# Keeproot

Keeproot helps you and your AI assistant work with files in local project folders. You can read materials, process spreadsheets, save results and return to earlier work.

## What it does

- **Read and edit.** Browse documents, images and spreadsheets. Edit Markdown and text in place; open complex formats in their usual apps.
- **Process tables.** Combine, clean, group or pivot CSV/XLSX data. Check the preview before saving a new file.
- **Continue work.** Reopen a saved setup, review source changes or reuse it with new materials.
- **Put a delivery together.** Keep file references, notes and result previews on a Board, then export it as HTML.
- **Recover selected work.** Protect files before making changes, preview a restore and return if you chose the wrong point.
- **Work with an AI assistant.** The CLI exposes the same projects, files and saved results as the interface.

The assistant interprets your request and proposes changes. Keeproot records file locations, versions and relationships, runs supported operations and checks saved files.

## Limits

This is a Windows preview with unresolved test failures. Long-running native use, first installation on another machine and continuation between different AI products still need verification.

Keeproot does not replace a full document editor. Spreadsheet previews do not calculate Excel formulas. Recovery covers the files and supported work state declared beforehand; it cannot restore unsaved editor buffers, AI chats or remote services.
